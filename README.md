# 🚦 Smart Semaphore Database

Solução de **modelagem, criação e avaliação** de bancos de dados **SQL (MySQL)** e **NoSQL (MongoDB)** para um **Sistema Inteligente de Gestão de Tráfego Urbano (IoT)**.  
O projeto inclui scripts para **geração de dados**, **população das bases** e **métricas comparativas** entre os modelos.

---

## 📁 Estrutura do Projeto

- **`build_mysql_sb.py`** — Cria e estrutura o banco de dados MySQL.  
- **`generate_data.py`** — Gera dados simulados de dispositivos, sensores e fluxo de tráfego.  
- **`eval.py`** — Avalia e compara a performance entre MySQL e MongoDB.

---

## 🛠️ Pré-requisitos

- Python 3.10+
- MySQL Server (local)
- MongoDB (local ou Atlas)
